Broken Screen Resizer
=====================
Monitörün bozuk kısmını Windows'tan gizler. / Hides the broken part of a monitor from Windows.
https://github.com/HErkanuzun/BrokenScreenResizer

TÜRKÇE
------
Kurulum gerekmez.
1. BrokenScreenResizer.exe'yi çalıştır.
2. Bozuk monitörü seç, monitör çiziminde bozuk kenarı içeri sürükle.
3. Yöntemi seç (Yazılım modu önerilir) ve Uygula'ya bas. Görüntü doğruysa "Böyle kalsın" de.

Kaldırma: Uninstall.bat dosyasını çalıştır (ya da programdaki "Programı kaldır…").
Program bilgisayarda yaptığı her değişikliği geri alır; sonra bu klasörü silebilirsin.

Klasördekiler:
  BrokenScreenResizer.exe  Program (sanal monitör sürücüsü içine gömülüdür)
  Uninstall.bat            Tam kaldırma
  driver\                  Sanal monitör sürücüsü; exe'deki ile aynıdır, incelemek veya elle kurmak için
  LICENSE.txt              MIT lisansı

ENGLISH
-------
No installation needed.
1. Run BrokenScreenResizer.exe.
2. Pick the broken monitor and drag the broken edge inward on the monitor drawing.
3. Choose a method (Software mode is recommended) and press Apply. If the picture is right, choose "Keep".

Uninstall: run Uninstall.bat (or "Uninstall…" in the app).
The app reverts every change it made to the computer; then you can delete this folder.

Contents:
  BrokenScreenResizer.exe  The app (the virtual monitor driver is embedded in it)
  Uninstall.bat            Full uninstall
  driver\                  Virtual monitor driver; same as the embedded one, for review or manual install
  LICENSE.txt              MIT License
